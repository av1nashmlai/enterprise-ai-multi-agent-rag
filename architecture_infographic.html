Enterprise AI Knowledge & Decision Support System

Autonomous Multi-Agent RAG Platform for Heterogeneous Enterprise Documents

📥 1. Multi-Format Ingestion

Unified parsing layer supporting 4 enterprise file types with rich schema extraction:

  • PDF: Page-aware text parsing via pypdf.
  • TXT: Unstructured raw log parsing.
  • CSV: Key-value row serializer via pandas.
  • Excel (XLSX): Multi-sheet extraction via openpyxl.

🗄️ 2. Knowledge Store

High-efficiency chunking & local vector database:

  • Chunking: RecursiveCharacterTextSplitter (800 tokens, 150 overlap).
  • Vector Store: Local persistent ChromaDB.
  • Dual Embeddings: NVIDIA NIM (nemotron-3-embed-1b) & OpenAI (text-embedding-3-small).

🛡️ 3. Safety & Guardrails

Comprehensive pre- and post-processing reliability controls:

  • Prompt Injection: Regex screening blocks adversarial prompts.
  • Privacy Filter: Blocks sensitive credentials & PII requests.
  • Hallucination Audit: Validator Agent grades factual adherence.
🤖 Autonomous Multi-Agent Reasoning Engine (LangGraph)

1. Planner Agent

Decomposes complex enterprise prompts into 1-3 atomic search sub-queries.
➔

2. Retriever Agent

Executes VectorSearchTool across ChromaDB & catalogs source provenance.
➔

3. Reasoning Agent

Deductive synthesis across context with mandatory inline citations.
➔

4. Validator Agent

Executes HallucinationAuditTool; assigns PASSED / FLAGGED badge.

⚠️ Key Engineering Challenges & Mitigations

Tabular vs. Semantic Search: Vector embeddings struggle with dynamic SQL aggregations (SUM/AVG). Mitigation: Headers serialized into each row chunk to retain full context.
Remote Model Lifecycle: Cloud endpoints deprecate models over time. Mitigation: Automatic fallback cascades across active NVIDIA NIM / OpenAI endpoints.
Multi-Agent Latency: 4 sequential agent steps increase response time. Mitigation: Live status streaming via st.status for real-time visibility.
